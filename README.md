Address Book in C
Project Overview
A console-based Address Book application developed in C to manage contact information.
This project demonstrates practical use of structures, functions, pointers, file handling, header files, and modular programming.

 Features
- Add contacts
- Search contacts
- Edit contact details
- Delete contacts
- Display contacts
- Store contact information in a CSV file
- Load contact information from the file
- Input validation

Technologies Used
- C Programming
- GCC Compiler
- File Handling
- CSV File Storage
- Git & GitHub

C Concepts Used
- Structures
- Arrays
- Strings
- Pointers
- Functions
- Header Files
- File Handling
- Modular Programming
- Data Validation
